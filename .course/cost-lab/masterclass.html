The shape of the team can change

The old work might be research, drafting and handoffs. The new work includes directing a workflow, checking evidence and improving the system. Skills move around the work; a headcount reduction is not the only outcome.

Three layers of capability

Using an existing model

Inference means running a model to get a result. Budget for workflow engineering, context selection, evaluation, integration and human review.

Learning from good examples

Supervised fine-tuning trains a model on examples of desired behavior. A separate model-training project needs suitable data, labeling, specialists, compute and held-out evaluation.

Learning from a reward signal

Reinforcement learning improves behavior against a reward. Budget for the reward definition, evaluation environment, experiments, compute and specialists. First establish a task where those investments have a measurable purpose.
