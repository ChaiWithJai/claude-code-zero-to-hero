What this viewer records
Claude Code exports native OpenTelemetry to this local process. Requests show model usage estimates; Tools shows the span hierarchy; Result displays the exercise output. Prompt text, tool input, account identities and raw model responses are excluded from retained telemetry. The result file is intentionally visible because it contains synthetic practice data.
No Docker, database, separate collector, OpenInference SDK or model call is needed to run the viewer. History is bounded to 1,000 records per type.
