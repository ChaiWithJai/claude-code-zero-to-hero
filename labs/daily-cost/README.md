# What could AI change in your business?

A story-led masterclass for people who have heard about Claude and want to understand its business use. You do not need to know what a daily driver or token is.

Run `node cost-lab serve` and open the printed localhost URL. The visual makes no model calls and requires no account setup.

To present a real Claude Code session, follow [the two-terminal live exercise](LIVE.md). It includes a no-model rehearsal and a local Requests → Tools → Result viewer.

Start with [the business exercise](business-practice.md). Choose a revenue or cost hypothesis, predict the outcome, and compare the result with its baseline. Then find your industry in the optional 11-sector, 74-industry explorer. Related Databricks sources and authored adaptations are labeled separately.

Keep the offer, business judgment and release decision human. Ask your sidekick to make a small analysis or prototype using the supplied synthetic pilot and brief.

The optional `/trace` page and `node cost-lab demo` explain token rates after the business question is clear. `node cost-lab import /path/to/stream.jsonl --serve` reads one chosen stream-json export, keeps usage metadata and leaves actual billing and acceptance unknown. It makes no model calls, scans no account folders, and changes no integrations.

API-equivalent list rates, subscription fees, API credits and actual cash charges are different quantities. The bundled rates were checked 2026-10-20. Human time value and business lift are explicit scenario assumptions.

The free repository supports self-directed practice. Claude Code Daily Driver is the planned guided-practice offer. Claude Code Zero to Hero is the premium live workshop. Offer prices and dates are unset. Repository access must be available before a shared link works.
