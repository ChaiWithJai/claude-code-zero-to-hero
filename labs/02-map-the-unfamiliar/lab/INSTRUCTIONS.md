# Map the unfamiliar

Locate the terminal, agent, working folder, access controls, and output.

## Try it

1. Open inputs/sample-note.txt and identify what is already in the workspace.
2. Draw or describe five labels: you, terminal, Claude Code, working folder, and result.
3. Before running the prompt, predict what it will read and whether it should create any files.
4. Run the read-only orientation prompt, or analyze the supplied example if access is blocked.
5. Compare the result with your file manager. Explain why a working folder is not a complete sandbox.

## Starting prompt

Read the inputs and write your prediction before using this prompt.

```text
List the files in this workspace and summarize inputs/sample-note.txt. Do not create, edit, or delete any files. Tell me which input you used.
```

## Keep

Save your output in `outputs/`. Keep your prediction, source checks, model revision, and evidence route in `outputs/NOTES.md`. Your notes can stay private.

## Check

- Can you locate each role without relying on screen coordinates?
- Did you distinguish organizing work from enforcing access?

The launcher offers hints, examples, and a work check. A check of an open-ended note is a prompt for review, not a grade.
