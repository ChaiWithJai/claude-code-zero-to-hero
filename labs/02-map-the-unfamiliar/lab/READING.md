## Turn overwhelm into a visible map

Draw five labels: you, terminal, Claude Code, working folder, and result. The terminal hosts a text interface. Claude Code is the agentic application running there. The working folder is where you start the session and organize the practice material. The result is something you inspect, not something you accept because it looks polished.

Add access as a separate annotation. Your instructions say what you want. Tool permissions and operating-system controls govern access and actions. A working folder helps organize the task but is not a guarantee that the program is isolated from the rest of your computer.

As you watch a demonstration, point to only three places: the request, the tool action, and the result. The map stays simple until those are recognizable. If your interface differs, use the official documentation and locate the equivalent role rather than memorizing screen coordinates.

## Open your practice space

Download and extract the learner kit. Find the practice-space folder in your file manager. It contains sources, prompts, and expected examples. Keep source material separate from new outputs so you can tell what changed.

Follow the official quickstart for your operating system and approved account access. Confirm that Claude Code opens in the practice-space folder. Use the documented help interface to inspect available commands. Do not install a new terminal just to match the instructor; the default terminal is sufficient for this course.

If installation or login is blocked, record the blocker in your binder and continue by inspecting the included example outputs. You can predict, verify claims, and revise a delegation brief without execution. Mark that evidence as observed or analyzed; return to the execution task after access is resolved.

Official reference: https://code.claude.com/docs/en/overview (checked 2026-10-19). Start with Getting started and Quickstart. Use the documentation navigation to find installation or permission guidance when your interface differs; confirm details for your installed version.
