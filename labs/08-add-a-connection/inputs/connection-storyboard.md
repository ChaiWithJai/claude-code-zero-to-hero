# A connection without a setup detour

This is a hypothetical storyboard, not a tested integration.

1. Wish: compare three options in a spreadsheet. Predict what data needs to leave the practice folder.
2. Local route: create comparison.csv and inspect it. This works without an account connection.
3. Browser route: with permission, open a disposable spreadsheet in a signed-in browser and import that CSV. Predict the account, destination, and exact write before acting.
4. Pause before confirmation. Verify the destination and scope. Cancel if they differ.
5. Inspect three rows and preserve unknown delivery. Record the actual changed file, not merely a successful tool response.
6. If access is unavailable, keep the CSV and mark browser access planned. A phone demo does not establish that your phone route works.

Choose a direct integration only when it serves a repeated task better than this export. Treat account access as a separate capability to test.
