## Add a connection when it earns its place

Make an access inventory: capability, purpose, available account, permission status, test action, and fallback. Your Google checklist can include Calendar, Mail, Docs, Sheets, and Slides, but each should have a reason to exist. “Planned” is an honest and useful status.

Browser control, a direct service integration, and a local file export are different routes. Choose the smallest route that serves the exercise. A CSV can be inspected locally and imported into a spreadsheet without granting a tool access to an entire account. Browser actions can affect the signed-in session, so define the allowed action before testing.

For the workshop, use the instructor’s sanitized browser demonstration or the included storyboard. The learner exercise is to predict the action, identify the access requirement, and choose a fallback. Setting up every account, a phone route, or custom connectors belongs in an optional lab after the core experience.
