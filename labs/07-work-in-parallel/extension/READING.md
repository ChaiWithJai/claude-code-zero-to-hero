## Separate dependencies from parallel work

Draw a small dependency map. Extracting dimensions and extracting warranty terms from separate source cards can be independent. Recommending a desk depends on knowing the constraint and the checked comparison. Draw an arrow only when one step needs another step’s result.

Asynchronous work can continue without your constant attention. Concurrent work has more than one task progressing during an overlapping period. Neither guarantees faster or better results. Shared files, incomplete inputs, usage limits, and review effort can remove the benefit.

First simulate the branches on paper. Give each branch its own output and define where the results meet. In this course, a simulated branch map demonstrates planning. Only a recorded or observed multi-session run demonstrates actual concurrent execution. Keep that distinction in your capability record.
