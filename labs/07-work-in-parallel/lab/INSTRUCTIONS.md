# Plan work that can overlap

Distinguish dependencies from independent work before adding sessions.

## Try it

1. Read inputs/meeting-notes.txt and inputs/event-notes.txt.
2. Draw or describe three tasks. Name what each one needs and produces.
3. Mark one dependency and one branch that can proceed independently.
4. Give independent branches separate output files and name where results join for checking.
5. Record whether your evidence is a plan, a simulation, or actual concurrent execution.

## Keep

Save your output in `outputs/`. Keep your prediction, source checks, model revision, and evidence route in `outputs/NOTES.md`. Your notes can stay private.

## Check

- Is a claimed dependency really needed?
- Could two branches overwrite the same file?
- Did you distinguish asynchronous from concurrent work?

The launcher offers hints, examples, and a work check. A check of an open-ended note is a prompt for review, not a grade.
