# Pause and predict: a local loop

This is an illustrated sequence in words, not a recording of a live agent. Use meeting-notes.txt in this folder.

1. Request: turn the notes into an action brief. Before starting, predict which source must be read.
2. Read: the agent inspects meeting-notes.txt. Pause: does it have an owner and due date for every action?
3. Inspect: Nora owns the invitation and Thursday is supplied. Projector ownership is not supplied. A lunch suggestion is not a decision.
4. Choose: preserve the unknown and ask a clarification question instead of inventing an owner.
5. Review: compare each action with its source. If a suggestion became a decision, request that exact repair.

For actual observation, use the starting prompt and watch your own agent session. Record what it really did. The route can differ from this storyboard.
